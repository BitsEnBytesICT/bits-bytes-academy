Calvin Coolidge’s Cool College, once we started including lots of if statements in a function, the code became a little cluttered and clunky. Luckily, there are other tools we can use to build control flow.

else statements allow us to elegantly describe what we want our code to do when certain conditions are not met.

else statements always appear in conjunction with if statements. Consider our waking-up example to see how this works:

if weekday:
  print("wake up at 6:30")
else:
  print("sleep in")

Copy to Clipboard

In this way, we can build if statements that execute different code when the condition is not met. This prevents us from needing to write if statements for each possible condition — we can instead write a blanket else statement for all the times the condition is not met.
