## Local authoring plan — implemented in this revision

Keep all 13 IDs, kinds, topic order and legacy quiz definitions. Build an original
station-monitoring/dispatch thread through the chapter:

- Start with a small runnable preview and a prediction about changed input length.
- Use an existing repeated report to expose a missed item, then refactor one rule.
- Repair and extend an indented loop; separate repeated output from a final summary.
- Make configurable numbered runs using range, including zero repetitions.
- Trace condition, state update and stopping with a useful countdown/charge report.
- Traverse a changing-size measurement list with a running total; test empty input.
- Explore nontermination safely with Stop/Ctrl+C; show growing-list and missing
  update causes, keeping the supplied starter runnable.
- Search for the first threshold crossing; record inspected values and stop, with
  no-match and first-match cases to detect misplaced break.
- Skip invalid readings while keeping later valid readings; distinguish zero and
  negative boundaries and demonstrate why break is not a filter.
- Traverse uneven nested batches, preserving both row reports and a grand total.
- Compare an explicit transformed-list loop with a comprehension; preserve inputs.
- Contrast filtering with conditional replacement; test the exact boundary.
- Finish a multi-stage batch report that builds on supplied data, diagnoses a
  fault, flattens, filters, transforms, totals and reports meaningful results.

Each coding page needs connected stages, examples with exact output, diagnostic
hints/feedback, independent partial progress and changed-input checks. Avoid a
grader that passes copied constants or requires arbitrary variable names unless
the names are explicitly part of the task. Keep stateful loop probes bounded;
the test harness must not hang on intentionally nonterminating mistakes.

Enhance the ten existing local quiz questions with specific wrong-choice feedback;
add an original nested-loop code-blank variant through the existing format-version
mechanism, preserving old attempts. Source review is complete enough to author
this chapter. The original rewrite is implemented in `loops-lessons.mjs`,
`loops-advanced.mjs` and `loops-quiz.mjs`.
