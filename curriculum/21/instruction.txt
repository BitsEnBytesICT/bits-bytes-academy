Boolean Operators: or
5 min

The Boolean operator or combines two expressions into a larger expression that is True if either component is True.

Consider the statement

Oranges are fruits or apples are vegetables.

This statement is composed of two expressions: oranges are fruits, which is True, and apples are vegetables, which is False. Because the two expressions are connected by the or operator, the entire statement is True. Only one component needs to be True for an or statement to be True.

In English, or often implies that if one component is True, then the other component must be False. This is not the case in Python. If an or statement has two True components, it is also True.

Let’s take a look at a few examples in Python:

True or (3 + 4 == 7)    # True
(1 - 1 == 0) or False   # True
(2 < 0) or True         # True
(3 == 8) or (3 > 4)     # False

Notice that each or statement that has at least one True component is True, but the final statement has two False components, so it is False.
