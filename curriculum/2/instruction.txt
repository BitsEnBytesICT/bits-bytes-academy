Ironically, the first thing we’re going to do is explore how to tell a computer to ignore part of a program. Text written in a program but not run by the computer is called a
comment
Preview: Docs Loading link description
. Python interprets anything after a # as a comment.

Comments can:

    provide context for why something is written the way it is:

# This variable will be used to count the number of times anyone writes a post containing the word persnickety
persnickety_count = 0

    help other people reading the code understand it faster:

# This code will calculate the likelihood that it will rain tomorrow
complicated_rain_calculation_for_tomorrow()

Copy to Clipboard

    ignore a line of code and see how a program runs without it:

# useful_value = old_sloppy_code()
useful_value = new_clean_code()
