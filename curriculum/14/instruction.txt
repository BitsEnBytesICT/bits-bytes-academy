a SyntaxError. Python offers a solution:
multi-line strings
Preview: Docs Loading link description
. By using three quotation marks (""" or ''') instead of one, we tell the program that the string doesn’t end until the next triple quote. This method is useful if the string being defined contains a lot of quotation marks and we want to be sure we don’t close it prematurely.

leaves_of_grass = """
Poets to come! orators, singers, musicians to come!
Not to-day is to justify me and answer what I am for,
But you, a new brood, native, athletic, continental, greater than before known,
Arouse! for you must justify me.
"""

In the preceding example, we assign a famous poet’s words to a variable. Even though the quote contains multiple line breaks, the code still works!

If a multi-line string isn’t assigned to a variable or used in an expression, it is treated as a comment.
