Notice that when we perform division, the result has a decimal place. This is because Python converts all type int to type float before performing division. In older versions of Python (2.7 and earlier), this conversion did not happen, and integer division would always round down to the nearest integer.

Division can throw its own special error: ZeroDivisionError. Python will raise this error when attempting to divide by 0.
