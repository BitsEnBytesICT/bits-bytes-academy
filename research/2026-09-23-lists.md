## Foundation quiz — newly discovered interaction requirement

The [11-question quiz](https://www.codecademy.com/courses/learn-python-3/quizzes/create-python-list-quiz)
was inspected through completion. Concept coverage includes positive indexing,
append syntax, nested record construction, first-match removal, nested assignment,
mixed types, nested negative indexing, list-literal syntax, remove syntax,
single-index assignment and empty lists.

Eight questions use immediate single-choice grading. Three use **code blanks**:

- Click a token to fill the first empty slot; extra distractor tokens can remain.
- Duplicate visible tokens have separate available instances.
- Clicking a filled slot returns its token to the bank, preserving other slots.
- Check answer stays disabled while any slot is empty. A completely filled draft
  temporarily advances the visible progress percentage even before submission.
- Submission locks the answer and labels each slot correct/incorrect. One wrong
  slot fails the question; contextual feedback identifies the misconception.
- Next advances after submission. Results retain the attempted score and show
  correction/explanation for a wrong question; Retake starts another attempt.

A deliberately wrong row index verified per-slot failure feedback. The final
result was 10/11 (90%). Correct and incorrect code-blank submission were both
observed. The result page's blank-answer rendering had little accessible text;
do not claim its visual correction layout was fully inspected from the AX tree.

**The local quiz currently supports only single-choice questions.** Code-blank
questions, editable token placement, explicit submission, per-slot feedback,
keyboard access, draft persistence and compatible historical attempts are required
remaining work. Do not count this quiz as fully matched merely after improving its
choice feedback. Existing question/answer records must remain readable.
