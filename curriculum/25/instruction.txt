Great job! We covered a lot of material in this lesson, and we’ve increased the number of tools in our Python toolkit severalfold. Let’s review what we’ve learned this lesson:

    Boolean expressions are statements that are objectively either true or false.
    A Boolean variable is a variable that is set to one of the Boolean values, True or False.
    We can create Boolean expressions using relational operators:
        ==: equals
        !=: not equals
        >: greater than
        >=: greater than or equal to
        <: less than
        <=: less than or equal to
    if statements can be used to create control flow in your code.
    else statements can be used to execute code when the conditions of an if statement are not met.
    elif statements can be used to build additional checks into your if statements.
